One out-of-office auto-reply, written as if a houseplant sent it — the
succulent you forgot in February, surviving on nothing, and your email can
do the same. A [make.fun](https://make.fun/c/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047)
bounty entry.

Run `python3 main.py` and it writes the entry to `/output/entry.txt`.
